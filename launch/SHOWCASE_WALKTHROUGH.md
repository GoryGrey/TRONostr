TRONostr showcase walkthrough

Best first run:

```bash
npm install
npm run showcase
```

What the command shows:

1. The product summary: TRON-first telemetry, Nostr-first transport, optional webhook output.
2. The event stream: block telemetry, TRX transfer, USDT transfer.
3. The distribution story: relay publish count, webhook mirror count, SDK consumer count.
4. The operational story: queue and relay stats, latest block seen, processed event counts.

Follow-up commands:

- `npm run demo:status`
- `npm run smoke`
- `npm run verify:tron`
- `npm run verify:relays`
