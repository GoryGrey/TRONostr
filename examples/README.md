# Examples

These examples map directly to the current product story:

- `bot_example.ts`
  Whale/risk alert consumption.
- `block_telemetry_consumer.ts`
  Block telemetry consumption for dashboards or analytics.
- `webhook_receiver.ts`
  Secondary HTTP integration sink for mirrored events.
- `event_flow_example.ts`
  Direct view of the machine-readable TRONostr event envelope.

If you are new to the repo, start with:

```bash
npm run showcase
```
